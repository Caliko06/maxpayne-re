Max Payne in the browser

Fan project. This page is a notice about the game running at this address.

What this is

Max Payne (PC, 2001, v1.05) rebuilt to run in a browser: every function of the original MaxPayne.exe and its DLLs is statically recompiled from x86 to WebAssembly, and this site stands in for Windows, Direct3D 8, DirectInput and DirectSound. It runs on the copy of the game the project owner bought.

The game data served from this domain comes from that retail copy, so the game can be played in a browser without an installer. It is not sold, rented or licensed here. No game files are part of the project's source repository.

Your saves

Saved games and settings stay in your own browser (private origin storage). They are not uploaded to this server and they do not follow you to another device or another browser.

Takedown

If you hold the rights to this game and want this page or its game data offline, say so and it goes offline: the game data is one package, so removing it takes one action and the page stops serving the game while this notice stays up.
